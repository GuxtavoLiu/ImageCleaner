MÉTODO MAIS FÁCIL (RECOMENDADO):
─────────────────────────────────────────────────────────────

1. Dê um DUPLO CLIQUE no arquivo: build_exe.bat

2. Aguarde o processo (2-5 minutos)

3. Pronto! O executável estará em: dist\ImageCleaner.exe


═══════════════════════════════════════════════════════════════

QUANDO ATUALIZAR O CÓDIGO:
─────────────────────────────────────────────────────────────

1. Faça suas modificações no main.py

2. Dê um DUPLO CLIQUE no arquivo: build_exe.bat

3. O script irá automaticamente:
   - Limpar builds anteriores
   - Recompilar com o código atualizado
   - Gerar o novo executável

4. Teste o novo executável antes de distribuir!

✓ Python 3.7 ou superior instalado
